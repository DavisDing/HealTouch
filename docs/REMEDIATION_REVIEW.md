## 数据兼容和运维边界

- V1/V2 未修改。V3 只增加字段、表、索引、触发器，并清理与 README 冲突的旧角色授权，不删除患者、财务或旧审计记录。
- V3 的备注字段只能保护升级后的审批；无法恢复旧审批已经覆盖的备注。V3 回滚应使用升级前完整数据副本与匹配的旧二进制，不能简单删除触发器后当成安全降级。
- 备份使用 RSA 2048 公钥封装随机 AES 128 密钥，压缩内容使用带序号和结束记录认证的分块 AES-GCM；私钥用 PBKDF2-HMAC-SHA256（210000 次）派生的 AES 密钥加密。没有新增 Maven 依赖。默认密钥配置与加密私钥位于数据目录 backup-settings.properties，明文口令不落盘；每个包携带解密所需的加密密钥材料，允许跨机器使用口令恢复。
- `.healtouch-backup` 是当前格式 1、数据库版本 3 的完整还原包。还原校验当前二进制的 Flyway 迁移校验值与版本；不对不兼容包偷偷迁移。`.healtouch-emergency` 是损坏数据库和 journal/WAL/SHM 的加密原件副本，仅供技术恢复，不能冒充可直接还原的完整备份。
- 自动备份只在软件进程运行时调度；关闭期间不运行，下一次启动到设定时间后补做一次当日备份，不伪造离线日期的历史备份。若门店要求软件关闭时仍按时备份，需要另行确认 Windows 调度部署（NEEDS_CONFIRMATION）；本次没有修改系统任务、服务或环境。
- 数据库实例锁防止另一个 HealTouch 进程在本进程备份/还原期间写同一文件；池仍只有一个连接。所有任务在工作线程串行处理，耗时查询/备份仍会让后续任务等待，但不会在 JavaFX 线程执行 SQL。
- 季度演练提供真实临时测试库执行入口和审计记录，不表示本机已经完成演练。默认备份口令首次配置后保持不变；口令丢失无法从加密包恢复。
- 新患者选择器、折扣操作、备份/恢复页属于必要 UI 变更；账单查询与操作分两行避免新增按钮挤出原窗口宽度。无 Mock、无新增图标/样式/第三方 UI 依赖。

## Java 8 / JavaFX 验收入口

使用仓库工作流一致的带 JavaFX 的 Liberica Java 8 和 Maven 3.x，执行 `mvn --batch-mode --errors clean verify`。不要用不含 JavaFX 的普通 JDK 的结果代替桌面构建。

GUI 验收至少包括：

1. 管理员 A 登录后，由 B 停用/改角色/改密码；A 下一次请求必须退出。真实空闲 30 分钟退出，工作台定时刷新不续期，弹窗内输入计为活动。
2. 创建超过 100 位患者，在治疗/预存页翻页、搜索最早档案，分别收费和充值；检查空结果、加载失败、重新选择后旧余额/流水不会残留。
3. 人为将测试单 created_at 调到 31 分钟前，打开/搜索账单不改数据；系统维护作废后每张只记录一次 SYSTEM 日志。过期收费不扣预存、不写支付。主动取消收银应作废并记录操作者。
4. 前台在收银弹窗申请折扣，管理员从账单页审批，前台按新金额收费；未经审批和全额折扣被拒绝。检查各渠道输入、总额不符时禁用确认。
5. 申请、审批、撤销、重新申请和执行退款；独立申请备注/审批意见保留，1 分金额分摊不生成零行，历史重叠请求被明确撤销而非永久挂起。
6. 管理员配置备份后手动生成、使用错误口令/篡改包/缺失紧急备份尝试还原，必须失败且不改生产数据；有效包通过两次确认还原后全会话退出。执行测试库恢复演练并核对审计。断开备份目录时工作台持续提示，成功后清除故障提示。
